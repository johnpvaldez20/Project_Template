# Domain

Put domain code in this directory.
The domain holds entities, state transitions, and use-case rules.
It does not call a network and it does not render a view.
It imports no other layer.
The import map is `architecture.import_rules` in `.governance/project.json`.
Read `docs/design/ARCHITECTURE.md`.
