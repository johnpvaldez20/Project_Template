# License text

This directory is empty of a license on purpose.
This template does not choose a license for the owner.

1. Choose an SPDX license identifier.
2. Put the license text in this directory.
3. Set `spdx.license_id` in `.governance/project.json`.
4. Set `spdx.copyright_line` to the copyright notice.
5. Replace the SPDX lines in each text file.

`LicenseRef-UNSET` is a marker until you do those steps.
It grants no rights.
Read `docs/governance/ADOPTING.md`.
